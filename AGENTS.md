# Repository instructions

Before starting any task in this repository, read both of these files:

- `docs/UI_LANGUAGE.md`
- `docs/UI_CONTROL_STANDARDS.md`

Treat them as the shared source of truth for UI design and interaction decisions.

For icon creation or modification, also read:

- `docs/ICON_AUTHORING_GUIDE.md`

Treat the icon authoring guide as the source of truth for icon shape and outline/filled variants.
