# 프로젝트 문서

프로젝트 메뉴는 홈·일정·할 일·문서·멤버·설정이다. 홈에는 전체 촬영을 날짜·시간순으로 표시한다. 카메라 배치와 장비 선택은 촬영 일정을 열어 관리한다. 예전 카메라·장비·촬영 모드 URL은 일정으로 이동하며, 기존 레퍼런스 URL은 문서 화면으로 연결된다.

## 편집

문서 탭에서 여러 문서를 만들고 이름 변경·복제·삭제·텍스트 내보내기를 할 수 있다. 블록은 텍스트, 제목 1~3, 글머리/번호 목록, 체크리스트, 인용, 콜아웃, 코드, 구분선, 이미지 주소, 레퍼런스를 지원한다.

- `/` 입력으로 블록 종류를 검색한다. 방향키·Enter·Escape로도 조작한다.
- 블록 왼쪽 `+`는 다음 블록 추가, `⠿`는 메뉴와 이동 핸들이다. 우클릭 메뉴에서 복사·잘라내기·붙여넣기, 복제·삭제·순서·종류·정렬·색을 변경한다. 클립보드 접근은 브라우저가 허용한 범위에서 동작한다.
- 텍스트를 선택하면 굵게·기울임·밑줄·취소선·인라인 코드·링크·색·강조·서식 제거 메뉴가 나타난다.
- Enter는 블록 분리, Shift+Enter는 줄바꿈, 블록 시작에서 Backspace는 앞 블록과 합치기, Tab/Shift+Tab은 들여쓰기다. 코드 블록에서는 Enter도 줄바꿈이다.
- 실행 취소/다시 실행은 버튼 또는 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y를 사용한다.
- 마우스는 핸들을 끌어 이동한다. 터치는 핸들을 400 ms 유지해야 이동을 시작한다. 유지 전에 8 px 이상 움직이면 이동을 취소하고 일반 스크롤을 허용한다. 본문에서는 항상 일반 스크롤과 텍스트 선택을 유지한다.

## 레퍼런스 블록

`/레퍼런스`에서 프로젝트에 이미 연결된 자료 또는 자료 워크스페이스의 레퍼런스를 검색한다. 자료를 새로 가져오면 기존 권한과 리비전 검사를 거쳐 프로젝트에 연결한 뒤 블록에 참조 ID를 저장한다. 블록에는 원본 이름·메모·이미지·파일·링크가 표시된다. 캡션은 문서 안에서 독립적으로 작성한다.

블록 복제나 삭제는 자료 원본을 변경하지 않는다. 원본을 수정하면 다시 불러오기/저장 시 미리보기에 반영된다. 프로젝트에서 자료 연결을 해제하면 블록은 자리와 캡션을 보존하고 연결 해제 상태를 표시한다. 기존 프로젝트 레퍼런스는 하단 ‘연결 자료’에서도 관리할 수 있다.

## 저장·보안

문서는 선택적 `project.documents` 배열로 저장한다. 기존 문서 없는 데이터도 유효하다. 각 문서의 블록은 텍스트와 허용된 인라인 서식으로 저장하고 원시 HTML은 저장하지 않는다. 링크와 이미지 주소는 허용된 프로토콜로 제한하며, 렌더링 시 텍스트를 이스케이프한다.

자동 저장은 마지막 입력 후 600 ms에 기존 워크스페이스 리비전·변경 큐를 사용한다. 저장 때문에 편집 영역을 다시 만들지 않아 커서와 선택을 유지한다. 탭 이동은 저장을 먼저 마치며, 실패하면 내용을 유지하고 재시도를 제공한다. 충돌은 기존 서버 내용을 덮어쓰지 않는다. 문서/프로젝트 복사와 블록 이동은 원본 배열을 변경하지 않는다.

`tests/documents.test.js`와 `tools/qa-documents-browser.mjs`에서 구조 검증, 저장·충돌, 메뉴·서식·클립보드, 레퍼런스 가져오기, 복제, 드래그, 실제 터치 이벤트의 스크롤/이동 분리를 확인한다.
