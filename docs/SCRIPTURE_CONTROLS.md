# Scripture and QT controls

QT's existing human-readable date is a keyboard-accessible button opening a date dialog. Save uses the current note revision after flushing pending content; cancellation and failures preserve the stored note and draft. The date is a date-only string, independent of timezone conversion. For an automatically imported QT, the database's qt_date remains its original daily-source identity while note.date is the user's editable journal date. Changing that display date never regenerates passages, changes source links, merges notes or overwrites reflections/highlights.

The QT toolbar omits the redundant local routine save label while the top save state reflects active Scripture drafts/errors. Actionable local errors and retry remain. “매일성경” is a borderless, non-underlined source link immediately before the right-aligned passage toggle. An open right pane offers “말씀 >” to close it toward the right; a closed pane offers “< 말씀” to reopen it. Selected versions identify the passage header as [version] reference, without repeated verse labels.

The shared translation picker groups options by actual language metadata under 한글 번역 / 영어 번역 (unknown metadata stays under 기타 번역). The primary translation never appears in comparison choices. Switching primary to the comparison clears comparison with an explanation; duplicate saved preferences are repaired without changing primary. One available translation still has a usable no-comparison choice. Choices apply immediately and do not rewrite stored Bible/journal text.

Highlight rendering uses moderately richer colors through tokens while semantic stored IDs and purple remain unchanged. Foreground colors on pale backgrounds use suitable light-surface foreground tokens even in dark mode. Selection-menu A shows the actual rendered foreground and background together; mixed selections use an explicit A·/mixed label. A thin border keeps white/transparent previews visible. Selection, formatting and undo/redo refresh the preview.

Each live note has an ordered, bounded undo/redo timeline shared by rich text, verse formatting and verse memo changes. Ctrl/Cmd+Z undoes, Ctrl/Cmd+Shift+Z and Ctrl+Y redo. Annotation revisions remain current during undo saves; existing journal/block content and unrelated ranges are preserved. Native inputs/selects/textareas, unrelated editors and active composition retain their own handling. Undo history itself is session-local; applied changes use normal debounced persistence and failure/retry safeguards.

Validation uses synthetic authorized-source fixtures and temporary accounts, including daily-source identity, date cancel/failure/retry/reload in a different timezone, translation collisions/single version/persisted duplicates, exact/mixed color previews in light/dark, journal/annotation/memo/ordinary-note text ordering, Ctrl/Cmd keys, synthetic Korean composition, save failure/retry and mobile layouts. Chromium is exercised; OS IME and other browsers are not claimed tested. No unlicensed corpus or live user content is imported or modified.
