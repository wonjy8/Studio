# Spacing and control standards

The shared stylesheet defines a 4 px spacing scale (4, 8, 12, 16, 20, 24, 32). The current base form uses 12 px between fields and 6 px between a label and its control; feature-specific forms may use larger token values. Shared cards use 17 px padding, reducing to 16 px below 520 px. Workspace detail panels use 20 px desktop/tablet and 18 px below 760 px. Dialogs use 24 px desktop and 20 px at 900 px and below. Workspace content, header and tab gutters share the responsive --workspace-gutter token.

Standard text buttons, single-line inputs and selects have a 36 px minimum height on desktop and 44 px at 900 px and below. Content may expand rather than clip. They share 10 px horizontal padding and the 9 px control radius. Single-line inputs and selects use the same responsive border-box height; text buttons can grow for wrapped labels. Login fields and the login action use the same responsive standard. Textareas remain multiline; checkboxes and radios retain native geometry.

Icon actions use 36 px squares on desktop and 44 px at 900 px and below. The workspace rail is 56 px wide on desktop (40 px buttons and 8 px horizontal insets); its buttons are 40 × 40 px desktop and 40 × 44 px at 900 px and below. Calendar event chips remain compact 28 px controls, and project tabs retain their navigation sizing. Layout resize handles retain their 14 px visual square, 24 px pointer target and selected-object stacking order.

Keyboard focus remains visible. Default focus uses a 2 px ink outline with 4 px offset; workspace list/detail selectors use a 2 px blue outline with 2 px offset. Mobile fields use 16 px type to prevent focus zoom. Flexible grids, wrapping text and buttons prevent narrow layouts from forcing horizontal page scrolling. These tokens change presentation only; permissions, account state and persistence are unchanged.

Member and organization equipment use the same 200 px owner selector, control height, padding and tab row on desktop; both wrap the selector above the tabs on mobile. Loading placeholders reserve the same selector geometry. Independent equipment entry reads run in parallel, reuse only the current entry's inventory response, and refetch after mutations. Organization details are read on the organization management tab; unused personal invitations and claims do not block the equipment list.

Shared action metrics are finalized in `src/controls.css`, loaded after feature styles. Text actions use 36px desktop / 44px touch minimum height, 6px vertical and 10px horizontal padding, 8px icon/label gaps and 18px action glyphs. Icon actions use matching 36/44px square targets so mixed action rows align. Long text wraps and grows; text width follows its label. Inventory, materials card actions, admin actions, settings, forms, dialogs, context/format menus, and reference-board actions use this contract. Navigation, list/card selectors, calendar event chips and spatial editor drag/resize handles retain their separate roles.

Mobile (900px and below) uses one shared horizontal page gutter: 28px at widths of 360px or above and 24px below 360px. Desktop remains 24px. This shared gutter applies to workspace content, headers, tabs and full-screen menus. Do not add this gutter again to nested page contents. Dialog shells and bounded table/canvas scroll regions keep their own sizing contracts.

Touch-primary devices use pan-x/pan-y page gestures and a mobile-only viewport zoom hint to reduce accidental page pinch/double-tap scaling. Preserve component touch-action contracts, native one-finger scroll and text selection; never cancel all touchmove events. WebKit page gesture cancellation excludes local canvas zoom surfaces. Form input type stays at least 16px; larger document titles and app text-size controls retain their sizing. Browser and OS accessibility zoom may override page hints. Desktop retains the original viewport.

Text inputs, textareas and selects use transparent decorative borders while retaining border widths, spacing and control dimensions. Keyboard focus uses a distinct 2px accent outline with 2px offset; invalid values use a subtle error background alongside existing messages, and disabled/read-only states remain distinct. In forced-colors mode keyboard focus uses the system Highlight outline. Checkbox/radio geometry and structural content dividers are unchanged.

Workspace page containers default to full available width and share `--workspace-gutter`; individual document reading surfaces remain bounded. A4 uses `--document-page-width:210mm` and 20mm side margins, with `--document-reading-width` exposing its usable inner width. Bible reading reuses that inner width, with two equally shrinking bounded columns on desktop and existing verse-stacked comparison on mobile. Desktop navigation uses a 56px rail with 40px buttons, 8px side padding and 16px vertical gaps. The secondary sidebar has matching 16px top/bottom corner radii, equal 20px title offsets and a subtle left shadow; mobile navigation geometry is unchanged.

School semester navigation uses a small `학기·강의` section entry and larger semester-name rows. A single 20px slot shows a folder while collapsed, switches to the expand chevron on hover or keyboard focus, and keeps a down chevron while expanded. Native details/summary owns the toggle, including keyboard/touch behavior; course navigation remains separate. The section entry retains its existing route and mobile destination.

School credit requirements show every current course category as an inline numeric field, plus independent overall, major and liberal-education targets. Empty fields remain unset; zero is explicit. Enter or blur saves one field with a revision check, Escape cancels an unsent edit, and failures retain text with retry/cancel actions. New values use whole-credit steps; untouched legacy fractions, custom areas and explicit category mappings are preserved. Rendering blank fields does not create requirement records. The category-mapping editor is removed; stored mappings remain authoritative. Relevant GPA configuration retains its existing disclosure.

Desktop workspace navigation now uses 24px outline/filled glyphs in equal 40px targets, with a 56px rail, existing 8px insets and 16px gaps. The icon increase drives the minimal 4px rail/target expansion; mobile floating navigation stays unchanged. Course entry emoji controls use a fixed 40px slot and 8px title gap rather than inheriting the project-settings picker's 84px minimum width.

Document block entry controls align to the first editable line, including headings and multiline blocks. The local + opens a type menu without creating content; selecting a type creates one block and cancellation creates none. The blank tail is a focusable click/Enter/Space target: it adds one text block only when the last text-bearing block is nonempty, otherwise it focuses the existing empty block. Rich-text line breaks and empty formatting are treated as empty; media, references and dividers remain meaningful blocks. Document focus uses a subtle wash rather than an input box, with a system outline in forced-colors mode. Structural quote rules and saved color formatting remain intact. Screen flow stays continuous and the tail is excluded from A4 printing.
