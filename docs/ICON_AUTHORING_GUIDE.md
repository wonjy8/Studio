# 아이콘 제작 가이드

Studio에서 새 아이콘을 만들거나 기존 아이콘을 수정할 때 적용한다. 공통 UI 원칙은 `docs/UI_LANGUAGE.md`, 조작 크기와 터치 영역은 `docs/UI_CONTROL_STANDARDS.md`를 함께 따른다.

## 필수 조형 규칙

1. **기존 아이콘의 모양에 맞춘다.**  
   새 아이콘의 선, 모서리, 비례, 시각적 무게와 단순화 수준은 현재 Studio 아이콘과 어울려야 한다. 기존 아이콘과 나란히 보았을 때 다른 아이콘 세트에서 가져온 것처럼 튀지 않도록 한다.

2. **선형과 채움형을 모두 만든다.**  
   아이콘마다 선형(Outline)과 채움형(Filled) 두 가지 표현을 제공한다. 한 가지 표현만 추가하지 않는다.

3. **두 표현은 같은 생김새를 유지한다.**  
   선형과 채움형은 외곽 형태, 비례, 내부 요소와 세부 위치를 맞춘다. 선형이라고 내부를 전부 빈 선으로 만들 필요는 없다. 달력의 날짜 표시처럼 작고 반복되는 요소는 작은 크기에서도 또렷하고 보기 좋도록 점·칸을 채워 표현할 수 있다. 채움형은 같은 요소를 바탕색과 전경색을 반전해 표현한다. 외곽을 넓히거나 요소를 빼고 더해 의미가 달라지게 하지는 않는다.

5. **얼굴 표정은 필요한 요소만 쓴다.**  
   얼굴 아이콘은 외곽 원을 기본적으로 생략한다. 눈·눈썹·코만으로 표정이 읽히면 입을 그리지 않는다. 입은 표정의 의미를 전달하는 데 꼭 필요할 때만 추가한다.

4. **표현 방식으로 의미를 바꾸지 않는다.**  
   선형과 채움형은 같은 아이콘의 시각적 표현이다. 다른 기능, 상태 또는 대상을 나타내기 위해 모양을 달리하지 않는다. 상태 차이는 배경, 레이블, 배치 등 별도의 UI 신호로 전달한다.

## 기존 아이콘 언어와 구현 기준

- 공통 UI·내비게이션·배치도·조명 아이콘은 중앙 렌더러와 Ionicons 8.0.13의 SVG 자산을 사용한다. 화면별 임의 SVG나 별도 아이콘 라이브러리를 추가하지 않는다.
- Ionicons 원본 SVG의 `512 × 512 viewBox`를 유지한다. 기존 프로젝트 선택 아이콘은 해당 카탈로그의 캔버스를 유지한다.
- 선형과 채움형은 Ionicons에서 같은 이름의 `-outline` 파일과 기본 파일을 한 쌍으로 가져온다. `-sharp` 파일은 사용하지 않는다.
- 현재 맥락에 맞는 Ionicons를 재사용한다. 새 아이콘은 두 변형을 함께 등록하고 `src/design-system/icons/ionicons.js`의 이름 연결을 갱신한다.
- 아이콘만으로 제공되는 동작은 접근 가능한 이름과 툴팁을 제공한다.
- 아이콘 출처는 Ionic Team의 Ionicons 8.0.13이며 MIT 라이선스 전문을 `src/design-system/icons/IONICONS-LICENSE.txt`에 유지한다.

## 검토 항목

- 기존 Studio 아이콘과 선 굵기, 모서리, 비례, 시각적 무게가 맞는가?
- 선형과 채움형이 내부 채움 여부 외에는 같은 모양인가?
- 실제 표시 크기에서도 세부 요소를 식별할 수 있는가?
- 두 표현에서 기능과 의미가 동일한가?
- 공통 렌더러·아이콘 소스와 접근성 이름을 사용했는가?
- 출처와 라이선스를 기록했는가?
