# 말씀 워크스페이스

말씀 노트 / QT / 성경은 프로젝트와 별도로 계정에 저장된다. 말씀 문서는 공통 블록 편집기를 사용하고 QT는 별도 분할 양식을 사용한다. 두 화면 모두 자동 저장과 실패 시 입력 보존·재시도를 제공한다.

## 말씀 분류

말씀 노트에서 전체 / 주일말씀 / SFC / 수련회로 찾아본다. 노트의 ‘말씀 분류’ 버튼은 여러 개를 함께 선택할 수 있고 변경은 자동 저장된다. SFC와 수련회를 함께 선택하면 두 목록에서 같은 노트를 열며 수정 사항도 함께 반영된다. 기존 분류 없는 노트는 전체에 보존하고 임의로 분류하지 않는다. QT의 날짜별 기록과 가져오기는 그대로 유지한다.

## 장별 성경 읽기

성경 화면에서 책과 장을 선택하면 장 제목 아래 절 번호와 본문을 이어서 읽을 수 있다. 이전 장 / 다음 장은 책 경계도 넘나든다. 절을 누르거나 키보드로 체크해 선택한 뒤 말씀 노트로 인용한다. 검색 결과에는 책·장·절을 함께 표시하며, 원본에 없는 단락 소제목은 생성하지 않는다.

## 노션 성경 가져오기

1. 말씀 워크스페이스 → 성경 → 노션 ZIP 가져오기에서 내보낸 ZIP을 선택한다.
2. 권·구절 수를 확인한 뒤 가져온다. `구절, 구약·신약, 본문, 성경, 장, 절` CSV를 인식하고 `_all.csv` 중복 파일은 제외한다.
3. 책·장 또는 구절/본문 검색으로 찾은 구절을 선택해 새 노트를 작성하거나 노트의 ‘성경 구절’에서 기존 문서에 인용한다.

동일 파일을 다시 가져와도 구절이 중복되지 않는다. 같은 책·장·절의 본문은 가져온 값으로 갱신하며 이미 노트에 인용한 내용은 변경하지 않는다. 다른 계정의 성경·말씀은 조회할 수 없다. ZIP 파일과 성경 본문은 공개 앱 소스·배포 이미지에 포함하지 않는다. NAS 적용은 로그인한 계정에서 최초 한 번 ZIP을 가져와야 한다.

노션 Markdown/CSV 말씀 노트도 같은 가져오기에서 처리한다. 원래 속성을 보존하고 노션 페이지 식별자로 중복을 건너뛴다. 이미지 등 Markdown/CSV가 아닌 첨부 파일은 이 가져오기에서 등록하지 않는다. 업로드는 25MB, 텍스트 압축 해제 크기는 합계 32MB까지다.

## 매일성경 QT

QT 첫 화면은 날짜 내림차순의 기존 기록과 최상단의 ‘오늘 QT 만들기 / 이어쓰기’를 보여준다. 목록 진입에는 매일성경 접속이 필요하지 않다. 만들기를 누르면 한국 시간 기준 선택 날짜의 본문과 해설을 조회해 해당 날짜의 QT를 만들며, 기존 기록이 있으면 그대로 이어서 연다.

작성 화면은 왼쪽 기록 / 오른쪽 성경의 분할 보기다. 좁은 화면에서는 위아래로 배치한다. 왼쪽은 감사(번호 항목), 나에게 주는 말씀, 나의 적용, 기도제목(번호 항목) 순서다. 감사와 기도제목은 추가·삭제할 수 있고 Enter로 다음 항목을 만든다(Shift+Enter는 줄바꿈). 기도제목은 나의 기도 또는 다른 사람을 위한 기도로 구분하며 대상 이름을 입력할 수 있다. 항목은 날짜별 노트 안의 `qtJournal`에 안정적인 ID로 저장한다. `/api/scripture/qt/entries?kind=gratitude|prayers`는 자신의 비어 있지 않은 항목을 날짜·노트 ID와 함께 모아서 제공한다(`limit` 기본 100/최대 500, `offset` 페이지 조회). 별도 데이터베이스 화면은 아직 만들지 않는다.

오른쪽 본문은 생성 때 `qtVerses`로 함께 저장하므로 다시 열 때 공급자 접속이 필요하지 않다. 구절의 ‘표시·메모’에서 절 단위 글자색·하이라이트·메모를 지정한다. 사용자/책/장/절 기준의 `scripture_annotations`에 저장해 성경 화면과 모든 QT에서 같은 표시·메모를 공유한다. 원본 성경 CSV와 본문은 변경하지 않는다. 다른 계정에서는 조회할 수 없다.

기존 QT의 문서 블록은 자동 변환하거나 덮어쓰지 않는다. ‘기존 QT 기록 / 가져온 본문·해설’에서 열람하고 ‘문서 원본 편집’으로 기존 편집기에서 수정한다. 기존 기록에 구조화된 감사·기도 항목을 추가해도 원본 문서는 유지된다. 과거 QT는 가져온 성경 또는 기존 인용 블록에서 본문을 복구한다. 저장 실패 시 입력과 재시도 버튼을 유지하고, 미저장 상태에서는 화면 이탈을 막는다. 버전 충돌은 자동 덮어쓰기하지 않는다.

서버에서 `https://sum.su.or.kr:8888`에 접속할 수 있어야 한다. 공개 세션을 연 후 사이트의 `Ajax/Bible/BodyBibleCont`, `Ajax/Bible/BodyBible` JSON 응답을 조회한다. 공급자의 `Base_de` 날짜와 제목·본문 범위를 검사하고 원문 링크·출처를 보존한다. 접속 실패나 응답 형식 변경 시 오류와 재시도·원문·직접 QT 기록을 제공한다. 입력한 묵상 내용은 매일성경 서버로 보내지 않는다.

실제 매일성경 응답 검증은 외부 접속이 가능한 환경에서 별도로 수행해야 한다. 합성 JSON 응답을 사용하는 테스트가 실서비스 연결 성공을 뜻하지 않는다.

## 검증

- `node --test tests/scripture.test.js`: ZIP/CSV, 노션 노트, 성경 구절, 계정 분리, 저장 충돌, 중복 QT, 삭제 정리.
- `STUDIO_PLAYWRIGHT_MODULE=... node tools/qa-scripture-browser.mjs`: 합성 본문과 QT 응답을 사용하는 브라우저 검증.
- `STUDIO_QA_NOTION_ZIP=/path/to/private-export.zip`을 함께 지정하면 해당 파일을 로컬 임시 DB로만 가져와 확인한다. 업로드 파일·본문을 커밋하지 않는다.


책 선택은 구약·신약 그룹으로 구분한다. 가져온 본문에 명시된 `<제목>`은 해당 절 위 소제목으로 표시하고, `a)` 등 표식에 대응하는 주석은 현재 본문 맨 아래에 모은다. 주석 표식과 본문 위치는 서로 연결되며 주석 속 성경 이름/약어와 장:절은 해당 장의 구절로 이동한다. 원본 CSV와 저장 본문은 변경하지 않으므로 기존 가져오기에도 적용된다.

## 성경 버전과 분할 보기

성경 버전 선택기는 한글·영어 그룹을 제공한다. ZIP의 CSV 파일명에 있는 NIV, ESV, KJV, NASB, 개역개정, 개역한글, 새번역을 인식하고 그 밖의 이름은 파일명을 사용한다. 새 버전을 가져와도 기존 버전 본문과 QT의 기본 성경은 덮어쓰지 않는다. 기존 단일 성경은 다시 가져오지 않아도 버전 목록에 표시한다.

분할 보기를 켜면 왼쪽·오른쪽에서 버전과 책·장·검색·글자 크기를 독립적으로 선택한다. 각 패널에서 구절 인용, 소제목, 주석, 구절 메모를 사용할 수 있다. 구절 메모는 같은 책·장·절에 공통으로 연결되며 버전별로 복제하지 않는다. 작은 화면에서는 두 패널을 세로로 배치한다.
