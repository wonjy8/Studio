# 촬영별 구성

일정에서 촬영을 열면 멤버·장비 선택, 전용 대여 장비, 배치, 할 일을 관리한다. 촬영 모드 탭은 기존 동작을 유지한다.

## 저장과 호환성

- `contents[].configuration`에 `memberIds`, `gearIds`, `rentals`, `cameras`, `layoutObjects`를 저장한다.
- 새 촬영은 명시적인 빈 구성으로 시작한다. 전체 선택은 현재 선택 가능한 항목에만 적용하며 부분 선택도 저장한다.
- 기존 촬영의 `configuration`이 없으면 프로젝트 공통 구성을 읽어 표시한다. 기존 레코드를 일괄 변경하지 않고, 사용자가 구성 저장을 누르면 촬영 구성을 만든다.
- 공통 장비는 ID로 선택한다. 촬영 전용 대여 장비는 해당 구성 안의 별도 레코드이며 공통 `gear`, `equipment_items`, 재고·대여·반출·반납 테이블에 등록하지 않는다.
- `tasks[].shootId`가 없으면 기존 프로젝트 할 일, 있으면 해당 촬영의 할 일이다. 촬영 화면과 프로젝트 통합 화면은 동일한 레코드를 수정한다. 달력도 기존 날짜·시간 필드로 같은 할 일을 표시한다.

## 복제

- 촬영 정보와 저장된 구성·배치를 깊은 복사하고 새 촬영 ID를 만든다. 배치 항목, 전용 대여 장비, 할 일에도 새 ID를 부여하고 참조를 바꾼다.
- 멤버와 공통 등록 장비는 동일한 원본 자료를 선택하되, 선택 배열과 배치 데이터는 독립적이다.
- 기존 프로젝트 공통 대여 장비가 선택된 촬영을 복제하면 새 촬영의 전용 대여 구성으로 바꾼다. 원본 공통 장비는 보존한다.
- 대여 장비는 이름·분류·대여처·수량·도감 연결만 복사한다. 실제 대여·반출·반납 기록과 상태는 복사하지 않는다.
- 할 일은 이름·날짜·시간·깃발 등을 복사하지만 완료 상태는 항상 `false`로 시작한다. 원본 상태는 유지한다.
- 계정 영구 삭제 시 삭제되는 멤버·장비의 촬영 선택과 배치 참조도 정리한다.

## 검증

`node --test tests/shoots.test.js`는 구형 데이터 호환성, 미선택 기본값, 선택과 배치 분리, 복제와 할 일 독립성, 실제 재고·대여 기록 미생성, 잘못된 참조 거절, 계정 삭제 호환성을 확인한다.

`tools/qa-shoots-browser.mjs`는 전체·부분·해제 선택, 전용 대여 장비, 배치 편집, 촬영과 프로젝트 간 할 일 상태·내용 연동, 복제와 재접속, 모바일 화면을 실제 브라우저에서 확인한다.
